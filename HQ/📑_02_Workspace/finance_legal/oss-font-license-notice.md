# 오픈소스 폰트 라이선스 고지 — 나눔고딕

`[@golf-legal-privacy]` · 2026-07-30 · WBS 1.8

## 확인한 사실 (자체 검증)

창업자가 공유한 정보를 그대로 받아들이지 않고 직접 재확인했다.

- 나눔고딕은 **SIL Open Font License 1.1(OFL)**. 상업적 이용(유료 앱 판매, 광고, 인앱결제 포함) 가능, 무료. 저작권 문제 없음 — 이 부분은 창업자가 공유한 내용과 일치.
- OFL 조건상 폰트를 재배포/번들링할 때 **저작권 고지와 라이선스 조항을 함께 포함**해야 한다. 앱 내 "설정 → 오픈소스 라이선스" 화면에 문구를 넣는 것은 이 요건을 충족하는 가장 흔하고 안전한 방법(강제 사항이라기보다 업계 표준 관행에 가까움).
- 구현은 Google Fonts 배포판을 쓰는 `@expo-google-fonts/nanum-gothic` npm 패키지로 통합(MIT 라이선스로 패키징된 배포 코드 자체는 별개, 폰트 파일 자체 라이선스는 OFL 유지) — 별도로 폰트 파일을 직접 다운로드해 번들링할 필요 없음.

## 앱에 반영할 문구

설정 화면(WBS 1.6, `app/settings.tsx`)의 "오픈소스 라이선스" 섹션에 아래 문구를 그대로 넣는다.
