# UI/UX 디자인 스펙 — 마이템포 (WBS 1.4)

`[@golf-ux-designer]` · 2026-07-30 · 기반: PLANNING.md 5절(UX/내비게이션 구조), 확정 브랜드(이름/컬러/아이콘)

## 1. 디자인 시스템

| 토큰 | 값 | 용도 |
|---|---|---|
| `green` | `#436437` | 헤더, 프라이머리 버튼, 백스윙 구간 |
| `greenLight` | `#859A7D` | 저음 비프/시작 마커, 스크러버 진행 표시 |
| `greenDark` | `#2E4526` | 영상 플레이어 배경, 진한 텍스트 |
| `gold` | `#D4AF37` | 중음 비프/탑 마커, 다운스윙 구간, 보조 강조 |
| `goldLight` | `#F0D477` | 강조음/임팩트 마커, 재생 버튼 |
| `cream` | `#F7F1E0` | 헤더 위 텍스트, 카드 내 밝은 배경 |
| `ink` | `#26331F` | 본문 텍스트 |
| `muted` | `#6E7C66` | 보조 텍스트 |

**원칙**: 그라데이션 없는 플랫 디자인(최종 아이콘과 통일). 백스윙 구간은 항상 그린, 다운스윙/임팩트 구간은 항상 골드 계열로 색상 문법을 화면 전체에서 일관 적용 — 사용자가 "그린=길게, 골드=짧고 강하게"라는 리듬 감각을 색으로도 학습하게 함.

## 2. 화면별 요점 (`mytempo-ui-wireframes.html` 참고)

1. **프리셋 목록**: 그린 헤더, 화이트 카드 리스트. 각 카드의 비율 막대는 그린(백스윙)/골드(다운스윙) 분할로 비율을 시각화.
2. **내 스윙 목록**: 우상단 골드 파일(FAB) "+ 새 영상 마킹". 카드형 리스트(썸네일/이름/비율/날짜).
3. **스윙 마킹 화면(핵심)**: 상단 영상 영역은 진한 그린(`greenDark`)으로 몰입감 부여. 스크러버 위 3개 핀은 시작(연한 그린)/탑(골드)/임팩트(밝은 골드)로 구분. 마킹 버튼은 순서 강제(완료=그린, 현재=골드, 대기=아웃라인). 배속 칩·프레임 미세조정 버튼 포함.
4. **연습 화면**: 원형 링을 그린(백스윙 호)+골드(다운스윙 호)로 분할해 비율을 시각화, 재생 버튼은 골드로 강조.

## 3. 접근성 (기존 원칙 유지)

비프 진동 패턴(시작=짧게/탑=중간/임팩트=강하게), 소리·진동 선택 옵션, 고대비 모드, VoiceOver/TalkBack 레이블은 PLANNING.md 5절 원안 그대로 유지 — 이번 시각 디자인 반영과 별개로 구현 시 반드시 포함.
