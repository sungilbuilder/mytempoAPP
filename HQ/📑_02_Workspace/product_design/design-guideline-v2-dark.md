# 마이템포 디자인 가이드라인 v2 — 다크모드 리뉴얼

`[@golf-ux-designer]` · 2026-07-30 · 입력값: `benchmark-sports-fitness-ui-trends.md` ([@golf-benchmarker])
**Founder_Review: N** (기존 확정 브랜드 이름/컬러 정체성은 유지하고, 실행 방식만 업그레이드 — 골격이 되는 결정은 유지)

## 0. 방향 요약

기존 플랫 라이트 디자인(그린 배경 + 골드 포인트)은 정보량이 늘어날수록 밋밋해 보인다는 문제가 있었음. WHOOP/Nike Run Club 벤치마킹 결과를 반영해 **다크모드 기반 + 네온 포인트 컬러 + 초대형 숫자 타이포**로 전환한다. 단, 창업자가 확정한 "마이템포" 브랜드 아이덴티티(그린=백스윙/느림, 골드=다운스윙·임팩트/빠름이라는 색 의미 체계)는 그대로 유지하고, 다크 배경에서 도드라지도록 **네온 버전 토큰을 추가**하는 방식으로 진화시킨다. 브랜드를 갈아엎는 것이 아니라 "실행 퀄리티"를 프리미엄 스포츠 앱 수준으로 끌어올리는 것이 목적.

## 1. 색상 (HEX)

### 1-1. 배경/서페이스 (다크, 순검정 대신 차콜 — 눈 피로/저렴해 보임 방지)

| 토큰 | HEX | 용도 |
|---|---|---|
| `bg` | `#101410` | 화면 최하단 배경 |
| `surface1` | `#181D17` | 카드, 리스트 아이템 배경 (bg보다 한 단계 밝게) |
| `surface2` | `#20261F` | 모달/강조 카드, 눌림 상태 |
| `border` | `#2B322A` | 카드 구분선(얇게, 그림자 대신 사용) |

### 1-2. 브랜드 코어(기존 유지) + 네온 액센트(신규, 다크 배경용)

| `greenNeon` (신규) | `#5FC639` | **백스윙 구간, 프라이머리 강조**(버튼·활성 탭·비율 막대) |

| `goldNeonBright` (신규) | `#F7D464` | 하이라이트/눌림 상태 |

### 1-3. 텍스트

| 토큰 | HEX | 용도 |
|---|---|---|
| `textPrimary` | `#F5F7F2` | 본문/제목 (순백 대신 살짝 톤 다운) |
| `textSecondary` | `#A9B3A5` | 보조 텍스트, 캡션, 타임스탬프 |
| `textDisabled` | `#5C6459` | 비활성 상태 |

**색상 규칙(WHOOP 원칙 차용)**: 그린은 항상 "백스윙/느림/시작", 골드는 항상 "다운스윙·임팩트/빠름/강조"만 의미한다. 다른 의미로 그린·골드를 쓰지 않는다. 회색 텍스트는 본문에 쓰지 않고 보조 정보에만 사용한다.

## 2. 타이포그래피

| 스타일 | 크기 | 굵기 | 용도 |
|---|---|---|---|
| `displayNumber` | 56px | 800 | 템포 비율("3:1"), BPM 값 등 화면의 핵심 숫자 — WHOOP의 대형 회복점수 참고 |
| `h1` | 22px | 700 | 화면 타이틀 |
| `h2` | 17px | 700 | 카드 타이틀 |
| `body` | 14px | 500 | 본문 |
| `caption` | 12px | 400 | 보조 텍스트, 타임스탬프 |
| `micro` | 10px | 400 | 탭바 라벨, 뱃지 |

라인하이트는 숫자 계열 1.1, 본문 계열 1.4.

## 3. 여백 시스템

라이트 버전 대비 화면 전체 패딩을 20~30% 늘린다(다크모드는 여백이 좁으면 답답해 보임).

| 토큰 | 값 | 용도 |
|---|---|---|
| `space-xs` | 6px | 아이콘-텍스트 간격 |
| `space-sm` | 10px | 카드 내부 요소 간 |
| `space-md` | 16px | 카드 패딩 |
| `space-lg` | 24px | 화면 좌우 패딩, 카드 간 간격 |
| `space-xl` | 32px | 섹션 간 간격 |

## 4. 버튼 스타일

| 종류 | 배경 | 텍스트 | 사용처 |
|---|---|---|---|
| Primary | `greenNeon` 단색 | `#0A0F09`(진한 색, 밝은 배경 위 어두운 텍스트) | "이 템포로 연습하기", 저장 등 주요 액션 — 화면당 1개만 |
| Secondary(Play) | `goldNeon` 단색, 원형 | `#0A0F09` | 재생 버튼(원형, 지름 72px로 확대) |
| Ghost | 투명, `border` 1px | `textPrimary` | 미리듣기 등 보조 액션 |
| Disabled | `surface2` | `textDisabled` | 순서 강제된 마킹 버튼의 대기 상태 |

버튼 코너는 `radius.md(12px)`, 원형 버튼(재생)은 완전 원. 그림자는 사용하지 않고(RN 그림자는 플랫폼차가 큼) 눌림 상태는 배경을 `Bright` 토큰으로 전환해 표현한다.

## 5. 템포 그래픽 바 디자인 (핵심 시각 요소)

기존에는 얇은 10px 막대였음. 다크모드에서는 이 막대가 앱의 "얼굴"이 되도록 확대·강조한다.

- **두께**: 10px → **16px**로 확대, 코너는 완전 라운드(`radius.pill`).
- **색**: 백스윙 구간 = `greenNeon`, 다운스윙 구간 = `goldNeon`. 배경 트랙은 `surface2`.
- **비율 숫자 동반 표기**: 막대 위/아래에 `displayNumber` 스타일로 "3:1" 같은 비율을 크게 병기 — 막대는 보조, 숫자가 주인공(WHOOP의 "숫자 하나로 압축" 원칙).
- **연습 화면의 원형 링**: 기존 계획대로 원형 프로그레스 링 유지, 링 두께를 14px→**18px**로 확대하고 그린/골드 네온 색 적용. 링 중앙에는 비율 텍스트 대신 **BPM 또는 비율의 displayNumber**를 배치해 화면의 시각적 초점으로 삼는다.
- **마킹 화면 스크러버 핀**: 시작=greenNeon, 탑=goldNeon, 임팩트=goldNeonBright로 색 위계를 유지하되, 채도를 올려 다크 배경에서 선명하게.

## 6. 카드/리스트

- 보더 대신 배경색 차이로 구분: 카드 = `surface1`, 화면 배경 = `bg`. 얇은 1px `border`는 꼭 필요한 곳에만 보조로 사용.
- 카드 패딩 확대: 12px → 16px, 카드 간 간격 12px → 16px.
- 카드 내부 정보는 WHOOP 3단계 원칙 참고 — 리스트에서는 핵심 숫자(비율)만 크게 보여주고, 세부는 탭해서 진입.

## 7. 적용 우선순위 (golf-mobile-developer 참고)

1. `theme.ts`에 위 다크 팔레트/타이포/스페이싱 토큰 전면 교체(라이트 버전은 보관하되 기본값을 다크로 전환)
2. 프리셋 목록: 카드 배경 `surface1`, 비율 막대 16px 확대 + displayNumber 비율 표기
3. 연습 화면: 재생 버튼 확대 + goldNeon, 배경 다크 전환
4. 내 스윙 목록: FAB를 goldNeon으로, 카드 다크 전환
5. 탭바: 다크 배경 + greenNeon 활성 색

## 8. 추가 지시 반영 — NativeWind/컬러 재확인 (2026-07-30 추가)

창업자가 채팅으로 구체적인 팔레트(배경 `#0F172A` Deep Slate Charcoal, 포인트 `#84CC16`/`#A3E635` Cyber Lime)와 함께 **NativeWind(Tailwind) 도입**, **react-native-reanimated 애니메이션**, **글래스모피즘(BlurView)** 을 지시함. 아래와 같이 반영한다.

### 8-1. 스타일링 방식: NativeWind 채택
`className="bg-slate-900 text-lime-400 p-6 rounded-2xl"` 같은 Tailwind 워크플로우 요청을 그대로 받아들여 NativeWind를 도입한다. 다만 Tailwind의 **기본 팔레트 이름**(slate/lime)이 아니라, `tailwind.config.js`에 우리 브랜드 토큰을 커스텀 컬러로 등록해 `bg-bg`, `text-green-neon`, `bg-gold-neon` 같은 이름으로 쓴다. **패딩(`p-6`=24px)과 라운드(`rounded-2xl`=16px) 값은 창업자 지시 그대로 채택**(위 5·6절 수치와도 일치).

### 8-2. 컬러 재확인 — 왜 슬레이트+라임 대신 그린+골드 네온을 유지하는가
`#0F172A`(청회색 계열)+`#84CC16`(라임)은 Tailwind 기본 팔레트 예시값으로, 브랜드 고유색이 아니라 "NativeWind 사용 예시"로 보인다. 이미 앱 아이콘·스토어 이름(마이템포)·스플래시가 그린(`#436437`)+골드로 확정되어 있어, 여기서 슬레이트+라임으로 완전히 갈아타면 **아이콘과 앱 내부 UI의 색이 서로 다른 앱처럼 보이는 리스크**가 있다. 그래서 구조(다크 배경, 24px 패딩, 16px 라운드, 카드 깊이감)는 창업자 지시를 그대로 따르되, 포인트 컬러는 6절에 정의한 `greenNeon(#5FC639)`/`goldNeon(#EFC94D)`을 계속 사용한다. **이 부분만 창업자 확인 필요(Founder_Review=Y)** — 슬레이트+라임을 정말 원하면 다음 지시에서 확정해달라고 요청한다.

### 8-3. 애니메이션/글래스모피즘
- 템포 바(백스윙/다운스윙 구간)는 `react-native-reanimated`의 `useSharedValue`+`withTiming`으로 폭이 부드럽게 채워지도록 구현(프리셋 변경 시 60fps 트랜지션).
- 카드(특히 연습 화면의 메인 카드)는 `expo-blur`의 `BlurView`(`intensity=40`, `tint="dark"`) 위에 반투명 `surface1`(예: 70% 불투명도)을 얹어 글래스모피즘 표현.
