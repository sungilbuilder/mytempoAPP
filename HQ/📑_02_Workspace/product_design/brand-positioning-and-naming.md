## 1. 경쟁 구도 리서치 요약

| 앱 | 포지션 | 우리와의 차이 |
|---|---|---|
| Tour Tempo (공식 앱) | 자체 프레임 카운트 시스템(21/7, 24/8 등), 템포 트랙+포커스 트랙+영상분석까지 포함한 방대한 유료 콘텐츠 생태계 | 콘텐츠 라이브러리 중심, 무거움. 우리는 "내 스윙 하나"에 집중한 가벼운 개인화 도구 |
| Golf BPM / Golf Pro Tempo / Golf Tempo Pro | 사전 정의된 BPM/템포 트랙에 맞춰 스윙 연습(음악·프리셋 위주) | "일반화된 프로 템포"를 따라가는 방식 — 내 스윙을 저장하는 개념이 약함 |
| Golf Swing Tempo Analyzer/Pro | AI 영상 자동분석으로 템포 계산 | 우리 MVP는 의도적으로 AI 자동분석 제외(V2 이후) — 대신 수동 마킹으로 더 가볍고 즉시 사용 가능 |

**공백**: "내가 가장 잘 쳤던 스윙 하나를 직접 저장하고, 그 리듬 그대로 반복 연습한다"는 개인화·자기참조형 포지션은 경쟁 앱 대부분이 다루지 않음. 대부분 "프로의 템포를 따라하기" 또는 "AI가 분석해주기" 둘 중 하나.

## 2. 포지셔닝

**"프로의 템포가 아니라, 내 최고의 스윙의 템포."**
복잡한 AI 분석이나 방대한 유료 콘텐츠 라이브러리 없이, 내 인생 최고의 스윙 한 번을 숫자로 저장하고 소리로 재현하는 가장 단순한 개인화 리듬 트레이닝 앱.

## 4. 앱스토어 중복/상표 확인 결과

- "마이템포" 한글명으로 국내 앱스토어에 등록된 골프 앱은 검색되지 않음.
- 해외 App Store에 영문 "MyTempo"라는 앱이 존재하나, 골프가 아닌 피트니스(운동·영양 관리) 앱이라 카테고리가 다름 — 직접 충돌 가능성은 낮음.
- 정식 출시 전 특허청 상표 검색(키프리스)에서 "마이템포"/"MyTempo" 등록 여부는 golf-legal-privacy가 별도 확인 권장.

## 5. 아이콘 — 결정 과정

세 가지 방향(A. 펄스 볼 / B. 템포 바 / C. 스윙 아크)을 제시 후, A+B를 결합한 D안(골드 템포 바 위에 골프공 + 리듬 파동 링)으로 최종 방향을 좁힘. 색상은 다음 순서로 조정:
1. 최초: 다크 그린 그라데이션 배경
2. 마스터즈 그린(Pantone 342, #00594C) 시도 → **오거스타 내셔널이 그린+골드 조합을 연방 상표로 등록해 보호 중**이라는 리스크를 확인, 채택하지 않음
3. 대안으로 흰색을 섞은 연두 톤 그라데이션 시도
4. **최종 확정**: 창업자 지정 헥스 `#436437` 단색 배경 + 그라데이션 없는 플랫 디자인

최종 아이콘 파일: `brand-icons/mytempo-icon-final.svg` (배경 `#436437` 단색, 저음 바 `#859A7D`, 중음 바 `#D4AF37`, 강조음 바 `#F0D477`, 골프공 `#F7F1E0` 단색, 골드 펄스링 `#C9932B`). 초기 후보 3종(A/B/C)은 `brand-icons/` 폴더에 참고용으로 보관.
