# 랜딩/온보딩 페이지 기획

`[@golf-ux-designer]` · 2026-07-30 · WBS 1.7 · 입력: 창업자 피드백("앱을 켰을 때 랜딩페이지도 있으면 좋겠다, 인터랙티브하게")

## 1. 목적

PLANNING.md 3절에 "온보딩(템포 개념 1분 설명)"이 MVP 보조 기능으로 이미 있었으나 구체 화면 설계는 없었음. 이번에 첫 실행 시 보여줄 3장짜리 스와이프형 랜딩(온보딩) 화면으로 구체화한다. 목적은 두 가지: ①"내 최고의 스윙 리듬을 저장한다"는 핵심 가치를 15초 안에 전달, ②첫 진입 장벽을 낮추면서 자연스럽게 무료 시작을 유도(수익화 전략과 연결, 4절 참고).

## 2. 화면 구성 (3장 스와이프)

| 장 | 내용 | 인터랙션 |
|---|---|---|
| 1. 히어로 | 앱 아이콘 + "프로의 템포가 아니라, 내 최고의 스윙의 템포" 타이틀 + 한 줄 설명 | 상단 진행 바(스토리형 3분할), 스와이프/탭으로 다음 장 이동, "건너뛰기" |
| 2. 컨셉 설명 A | "내 인생 최고의 스윙 한 번을 저장하세요" + 미니 템포 바 애니메이션(그린→골드로 채워지는 루프) | 템포 바가 계속 반복 애니메이션(예시 3:1) |
| 3. 컨셉 설명 B + CTA | "그 리듬을 소리로 반복 연습합니다" + 비프 시각화(펄스 링) + **"무료로 시작하기"** 버튼 | 펄스 링 애니메이션, CTA 탭 시 메인 탭(프리셋)으로 진입 |

## 3. 인터랙션 디테일

- 상단 진행 바: 인스타그램 스토리처럼 3분할 바가 채워지며 현재 위치 표시.
- 스와이프 제스처 + 하단 점(dot) 인디케이터로 도트 탭으로도 이동 가능.
- 각 장의 일러스트는 정적 이미지가 아니라 실제 앱의 핵심 인터랙션(템포 바, 펄스 링)을 미리 보여주는 애니메이션 루프 — "이게 실제로 이렇게 움직이는 앱이구나"를 가입 전에 체감시키는 것이 핵심.
- "건너뛰기"는 항상 우상단에 노출(온보딩 강제 이탈 방지).
- 재방문 사용자에게는 표시하지 않음(최초 1회만, AsyncStorage에 `hasSeenOnboarding` 플래그).

## 4. 수익화 프레이밍 (4절 수익화 문서와 연결)

- 랜딩 마지막 CTA는 **"무료로 시작하기"**로, 가입 단계에서 유료 전환을 강요하지 않는다 — 첫 진입 마찰을 최소화하는 것이 우선(PLANNING.md 8절 "MVP 단계 본격 설계는 시기상조" 원칙과 일치).
- 다만 3번째 장의 문구에 "내 템포 여러 개 저장, 연습 히스토리는 추후 프리미엄"이라는 뉘앙스를 아주 살짝 언급(강조 아님, 각주 수준)해서, 나중에 실제 페이월을 만났을 때 "어? 갑자기?"라는 반응을 줄이는 정도로만 예고한다. 구체 문구/타이밍은 `monetization-plan.md`에서 golf-finance-analyst/golf-strategy-lead가 확정.
