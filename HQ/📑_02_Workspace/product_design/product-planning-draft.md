# 골프 템포 어플리케이션 — 서비스 기획서

> Tour Tempo 개념(백스윙 시작 → 탑 → 임팩트, 3구간 비율 템포)에서 영감을 받은 React Native(Expo) 기반 iOS/Android 크로스플랫폼 골프 스윙 템포 트레이닝 앱

---

## 1. 핵심 가치 제안

**내 최고의 스윙이 가진 리듬을 숫자로 저장하고, 그 리듬을 소리로 반복 훈련하여 몸에 새긴다.**

## 2. 타겟 페르소나

| 페르소나 | 상황 | 니즈 |
|---|---|---|
| 템포 방황형 중급 골퍼 (핸디 10~20대) | 라운드마다 스윙 리듬이 들쭉날쭉 | 객관적 숫자(비율)로 자기 템포 확인 |
| 레슨 병행 입문자 | 연습장에서 혼자 뭘 해야 할지 막막 | 단순한 리듬 신호를 따라 하는 낮은 진입장벽 |
| 슬럼프 탈출 상급 골퍼 | 좋았던 스윙 감각을 잃어버림 | 잘 맞았던 시절 영상의 템포를 수치화해 재현 목표로 삼기 |

## 3. MVP 범위

**핵심 기능 3개 (확정)**
- **A. 템포 프리셋** — 이름 붙은 비율 템포(3:1, 2.5:1, 3.5:1 등, 일반화된 라벨) 목록 중 선택
- **B. 내 스윙 등록** — 카메라롤 영상 → 스크러빙하며 백스윙 시작/탑/임팩트 3지점 수동 마킹 → 구간 시간·비율 자동 계산 → 이름 붙여 저장
- **C. 연습 화면** — 선택된 템포(프리셋 or 내 템포) 비율대로 비프음이 반복 재생되는 오디오 메트로놈

**MVP에 함께 포함할 보조 기능**
- 온보딩(템포 개념 1분 설명)
- 연습 세션 로컬 히스토리(날짜·템포·반복 횟수)
- 완전 오프라인 동작 (연습장 인터넷 환경 고려 시 필수)
- 배속(BPM) 조절 — 비율은 유지, 절대 속도만 변경
- 내 템포 여러 개 이름 붙여 관리

**MVP에서 제외 (V2 이후)**
- 컴퓨터비전 자동 스윙 분석
- 계정/로그인, 클라우드 동기화, 소셜/커뮤니티
- 웨어러블 연동, 다국어

**판단 근거**: MVP의 목적은 "내 템포를 재고 소리로 연습한다"는 핵심 루프의 가치 검증. 계정·클라우드·소셜은 이 루프가 실제로 유효한지 확인되기 전엔 리소스 낭비. 단, 로컬 히스토리와 오프라인 지원은 연습장이라는 실사용 맥락에서 없으면 제품이 성립하지 않으므로 MVP 포함.

## 4. 유저 플로우

**A. 템포 프리셋**
홈 → 프리셋 탭 → 카드 리스트(비율+미니 시각화 막대) → 미리듣기(비프 1회) → "이 템포로 연습하기" → 연습 화면 진입

**B. 내 스윙 등록**
내 스윙 탭 → "새로 추가" → 카메라롤에서 영상 선택 → 마킹 화면 진입 → ①백스윙 시작 탭 → ②탑 탭 → ③임팩트 탭(순서 강제, 완료된 단계만 마커 표시) → 실시간 구간 시간·비율 계산 표시 → 마커 위치 드래그로 재조정 가능 → 이름 붙여 저장 → "바로 연습하기"

**C. 연습 화면**
템포 선택 상태로 진입 → 재생 시 3단 비프(백스윙 시작=저음/탑=중음/임팩트=강조음)가 링 형태 진행 인디케이터와 동기화되어 반복 재생 → BPM 슬라이더로 실시간 배속 조절 → 정지 후 세션 기록 여부 선택

## 5. UX / 내비게이션 구조

**하단 탭 3개**: 프리셋 / 내 스윙 / 연습(중앙, 약간 강조). 설정은 탭이 아닌 우상단 톱니바퀴 아이콘.

**화면별 요점**
- 프리셋 목록: 세로 카드, 비율 미니 막대 시각화, 미리듣기+연습하기 버튼
- 내 스윙 목록: 저장된 템포 카드(이름/비율/날짜/썸네일) + 상단 "+새 영상 마킹" 고정 버튼, 스와이프로 삭제/이름 수정
- **스윙 마킹 화면(핵심)**: 상단 60% 비디오 플레이어, 하단 40% 스크러버+마킹 버튼 3개(순서대로만 활성화). 마킹 완료 지점은 스크러버 위 핀+타임코드로 표시. 배속 칩(1x/0.5x/0.25x)으로 슬로우모션 지원 — 특히 임팩트 구간은 프레임 수가 적어 0.25x가 정확도에 중요. 미세조정은 "◀1프레임/1프레임▶" 버튼으로 스냅 이동. 핀 탭 시 재마킹/삭제 팝업, 앞 단계 삭제 시 뒤 마킹도 초기화할지 확인.
- 연습 화면: 중앙 원형 프로그레스 링(백스윙 구간=파랑 호, 다운스윙 구간=주황 호, 호 길이 비율=템포 비율), 비프 타이밍에 링이 플래시

**예외 처리**: 카메라롤 권한 거부 시 딥링크 안내, 영상 3초 미만/60초 초과 경고, 마킹 미완료 이탈 시 확인 다이얼로그(임시저장 옵션), 비정상 비율(다운스윙 <0.05초) 소프트 경고

**접근성**: 비프음에 진동 패턴 동기화(백스윙 시작=짧은 진동, 탑=중간, 임팩트=강한 진동), 설정에서 소리/진동/둘다 선택, 고대비 모드, VoiceOver/TalkBack 레이블

## 6. 기술 아키텍처

**스택**: React Native + Expo, expo-router(파일 기반 라우팅, 화면 수 적어 적합)

```
app/(tabs)/index.tsx        # 프리셋 목록
app/(tabs)/my-swings.tsx     # 내 스윙 목록
app/(tabs)/practice/[id].tsx # 연습 화면
app/swing-editor/[uri].tsx   # 마킹 화면(모달)
features/tempo/              # 비율 계산 로직
features/audio-engine/       # 메트로놈 스케줄링
features/video-marker/       # 마킹 상태머신
store/                       # Zustand
db/                          # 데이터 저장
assets/audio/                # 사전 렌더링 비프 루프
```

**영상 재생/스크러빙**: expo-video(expo-av 후속, 최신 SDK 지원 상태 확인 필요) + `useVideoPlayer`. 프레임 단위 seek는 플랫폼(AVPlayer/ExoPlayer)별 GOP 구조 차이로 완전 보장 안 됨 → 슬라이더 대략 이동 + 미세조정 버튼으로 UX 흡수. 카메라롤 접근은 expo-image-picker.

**오디오 메트로놈 정확도**: JS `setTimeout`/`setInterval` 기반 실시간 스케줄링은 부정확 → **사전 렌더링된 비프 루프 오디오 파일**을 템포 비율에 맞춰 생성해 네이티브 loop 재생에 위임하는 방식 채택. 샘플 단위 정밀 스케줄링이 필요해지면 EAS Build + 네이티브 모듈이 필요(managed workflow 범위 밖). 백그라운드 재생은 `staysActiveInBackground` + iOS `UIBackgroundModes: ["audio"]` 설정.

**데이터 저장**: 프리셋은 `constants/presets.ts` 하드코딩. 사용자 템포는 프로토타입 단계 AsyncStorage로 시작, 추후 expo-sqlite로 이행 권장.

```
UserSwing { id, name, videoUri, createdAt,
  backswingStartMs, topMs, impactMs,
  backswingDurationMs, downswingDurationMs, ratio, thumbnailUri? }
TempoPreset { id, name, ratioBackswing, ratioDownswing, source }
```

**상태관리**: Zustand(재생 위치 등 고빈도 갱신 값이 많아 Context 대비 리렌더 이슈 적음, persist 미들웨어로 저장 연동 단순)

**리스크 Top 3**
1. 오디오 타이밍 정밀도 → 사전 렌더링 루프로 완화
2. 프레임 정확 탐색의 플랫폼 차이 → 슬라이더+미세조정 버튼으로 사용자가 직접 보정
3. 대용량 비디오 로컬 저장 → 원본 복사 대신 카메라롤 asset URI만 참조(원본 삭제 시 재생 불가 트레이드오프 존재)

**오늘 프로토타입 빌드 순서**
1. 프리셋 목록(하드코딩) + 연습 화면 메트로놈(사전 녹음 비프 루프) — 핵심 가치 가장 빨리 시연
2. 카메라롤 영상 불러오기 + expo-video 재생/스크러빙
3. 3개 마킹 버튼 → 비율 자동 계산 → AsyncStorage 저장
4. 저장된 내 템포를 연습 화면에 연결

## 7. V2 이후 확장 아이디어
- 컴퓨터비전 기반 자동 스윙 지점 감지
- 내 템포 추이 그래프(시간에 따른 변화, 굿샷 시절과 비교)

- 클럽별(드라이버/아이언/퍼팅) 템포 프로파일 분리

## 8. 수익화 (가설 단계)
MVP 단계에서 본격 설계는 시기상조. 방향성만 제시: 프리셋+내 템포 1개 저장+무제한 연습은 무료로 핵심 가치를 충분히 체험하게 하고, 내 템포 다중 저장/히스토리 분석/향후 자동 분석 기능을 유료(구독 또는 일회성)로 두는 프리미엄 모델이 자연스러워 보임. 실제 사용자 리텐션과 반복 사용 기능 데이터를 본 뒤 확정 필요.
