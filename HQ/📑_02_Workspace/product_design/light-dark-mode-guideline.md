# 라이트/다크 모드 토글 디자인 가이드

`[@golf-ux-designer]` · 2026-07-30 · WBS 1.6

## 1. 배경

창업자 피드백: "다크모드로 나온 게 좋고, 라이트모드로 변경할 수 있는 것도 필요할 것 같다." 다크모드(WBS 1.5, 네온 포인트)를 기본으로 유지하되, 라이트모드 전환 옵션을 추가한다.

**좋은 소식**: 라이트모드를 새로 디자인할 필요가 없다. WBS 1.4에서 이미 확정했던 원래의 플랫 라이트 팔레트(그린 `#436437`+골드 `#D4AF37`, 크림 배경)가 그대로 라이트모드 토큰이 된다. 즉 이번 작업은 "두 팔레트 중 하나를 고를 수 있게" 만드는 것이지, 새 팔레트를 또 만드는 게 아니다.

## 2. 토큰 매핑

| 역할 | 라이트모드 (WBS 1.4 재사용) | 다크모드 (WBS 1.5) |
|---|---|---|
| 배경(`bg`) | `#FAF8F2` | `#101410` |
| 카드(`surface`) | `#FFFFFF` | `#181D17` |
| 카드2(`surface2`) | `#F3EFE2` | `#20261F` |
| 구분선(`line`) | `#E3DFD1` | `#2B322A` |
| 본문 텍스트(`ink`) | `#26331F` | `#F5F7F2` |
| 보조 텍스트(`muted`) | `#6E7C66` | `#A9B3A5` |
| 백스윙 포인트(`green`) | `#436437`(그대로, 채도 낮음) | `#5FC639`(네온) |
| 다운스윙/임팩트 포인트(`gold`) | `#D4AF37`(그대로) | `#EFC94D`(네온) |
| 버튼 위 텍스트 | `#F7F1E0`(크림) | `#0A0F09`(진한 색) |

**원칙**: 라이트모드는 채도를 낮춘 "차분한 골프장" 톤, 다크모드는 채도를 높인 "프리미엄 스포츠 앱" 톤 — 두 모드 모두 "그린=백스윙, 골드=다운스윙·임팩트"라는 색 의미 체계는 동일하게 유지해 사용자가 모드를 바꿔도 헷갈리지 않는다.

## 3. 토글 UX

- 위치: PLANNING.md 5절에 이미 정의된 "우상단 톱니바퀴(설정) 아이콘" 안에 배치. 탭바에 새 탭을 만들지 않는다.
- 옵션 3개: **시스템 설정 따르기(기본값)** / 라이트 / 다크. 기본값을 시스템 설정으로 두는 이유는 최근 모바일 OS 다크모드 사용자가 다수라 예상치 못한 전환 없이 기기 설정과 자동 동기화되는 것이 요즘 앱의 표준 관행이기 때문(라이트/다크 모드 전환 시 사용자가 명시적으로 오버라이드 가능).
- 전환 시 화면 전체가 즉시 반영되고(리로드 없이), 선택값은 기기에 로컬 저장되어 다음 실행 시에도 유지.
