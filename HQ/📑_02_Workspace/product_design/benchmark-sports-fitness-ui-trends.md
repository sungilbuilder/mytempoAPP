# 스포츠/피트니스 앱 UI 트렌드 벤치마킹

`[@golf-benchmarker]` · 2026-07-30 · 신설 부서 첫 리서치

## 1. 조사 대상 및 핵심 발견

### WHOOP — 데이터 압축형 다크 UI
- **다크모드는 미학이 아니라 기능**: 검은 배경 위에서 컬러 데이터 포인트가 도드라지고, 새벽/야간 확인 시 눈부심을 줄임(WHOOP은 아침 6시 확인이 핵심 사용 패턴).
- **3색 의미 체계**: 그린(회복 좋음)/옐로(중간)/레드(위험·낮은 회복) — 색이 화면마다 항상 같은 의미를 가짐. "임의의 포인트 컬러"를 쓰지 않고 색상 자체가 정보.
- **점진적 정보 노출(3단계)**: ①한눈에 보는 점수(대형 숫자, 약 72pt 상당) → ②주간 트렌드 차트 → ③세부 그래프. 각 단계는 별도 화면으로 분리(한 화면에 아코디언으로 욱여넣지 않음).
- **타이포 위계**: 핵심 지표는 매우 크게, 보조 텍스트는 작고 흐리게 — 위계로 "뭐가 중요한지" 전달.
- 출처: [WHOOP Design Breakdown (925studios)](https://www.925studios.co/blog/whoop-design-breakdown)

### Nike Run Club — 볼드 타이포 + 라이트/다크 듀얼
- 굵은 대형 타이포그래피, 화이트 배경 + 블랙 텍스트의 강한 대비가 기본톤(2025년 기준). 다크모드 버전은 커뮤니티/컨셉 디자인에서 많이 다뤄질 만큼 요구가 높은 기능.
- 시사점: 프로 스포츠 브랜드 앱은 "색으로 화려하게"보다 "타이포 크기·굵기 대비"로 임팩트를 준다.
- 출처: [Nike Run Club Dark Mode 컨셉 (Dribbble)](https://dribbble.com/shots/11823562-NIKE-RUN-CLUB-Dark-Mode-iOS-App), [DesignRush 사례](https://www.designrush.com/best-designs/apps/nike-run-club)

### 2025년 다크모드 색상 트렌드 일반 원칙
- 배경은 순검정(#000000)보다 **차콜/니어블랙(#0E0E0E~#1A1A1A)**이 눈의 피로가 적고 프리미엄하게 느껴짐(OLED 고려해도 완전 순검정은 과함).
- 포인트 컬러는 **채도를 라이트모드보다 10~20% 높여야** 다크 배경에서 같은 시각적 무게감을 가짐 (예: 네온 그린 `#22C55E`, 일렉트릭 블루 `#3A82FF`, 앰버 `#F59E0B`).
- 본문 텍스트는 순백/니어화이트, 회색 텍스트는 절대 본문에 쓰지 않고 캡션·타임스탬프 등 보조 정보에만 사용.
- 다크모드는 **여백을 라이트모드 대비 20~30% 더** 줘야 한다 — 좁으면 답답하고 저렴해 보임.
- 포인트 컬러는 화면 전체에서 2~3개로 제한(경쟁 색이 많으면 산만함).
- 출처: [Dark Mode Color Palettes 2025 (Colorhero)](https://colorhero.io/blog/dark-mode-color-palettes-2025)

### 오토샷 등 국내 골프 앱
- 다크모드 적용 사례에 대한 구체적 자료는 검색으로 확인하지 못함(참고 자료 부족). 국내 골프 앱은 대체로 스코어/GPS 등 기능 중심 UI가 많고, 감각적 다크 UI 사례는 스포츠워치/웨어러블 앱(Whoop류)에서 더 참고할 만한 선례가 많음.

## 2. golf-ux-designer에게 제안하는 방향 (확정 아님 — 참고용)

1. **다크모드 기본 + 우리 브랜드 컬러를 "의미있는 포인트"로 재해석**: 이미 확정된 그린(#436437)/골드(#D4AF37)를 버리지 말고, WHOOP처럼 "그린=백스윙(길다), 골드=다운스윙·임팩트(짧고 강하다)"라는 의미 체계로 계속 사용. 다만 다크 배경에서 도드라지도록 채도/명도를 올린 네온 버전을 별도 토큰으로 추가.
2. **차콜 배경(#0E0E0E~#141914) 채택**, 순검정은 피함.
3. **핵심 숫자(비율, 템포)는 초대형 타이포로** — WHOOP의 "72pt 회복 점수"처럼, 템포 비율(예: "3:1")을 화면에서 가장 큰 요소로.
4. **여백을 넉넉하게, 카드 수를 줄이고 화면당 정보량을 압축** — 프리셋 카드도 지금보다 여백을 키우고 불필요한 보더 대신 배경색 차이로 구분.
5. **미니멀 카드**: 얇은 보더 대신 살짝 밝은 서페이스 컬러(카드=배경보다 한 단계 밝은 차콜)로 구분, 그림자 대신 색 대비로 depth 표현(RN 그림자 렌더링은 플랫폼차가 커서 색 대비가 더 안전).
