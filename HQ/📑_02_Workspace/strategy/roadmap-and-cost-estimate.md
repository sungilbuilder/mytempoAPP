| 1. 코어 프로토타입 | 프리셋 목록 + 메트로놈(사전 렌더링 비프) | 2~4일 | PLANNING.md 빌드 순서 ①번, 핵심 가치 최초 검증 |
| 2. 영상 마킹 기능 | 카메라롤 로드 + expo-video 스크러빙 + 3점 마킹 + 비율 계산 | 5~8일 | 리스크 1순위(프레임 탐색 정확도) 구간, 실기기 확인 필수 |

## 2. 비용 추정

| 항목 | 비용 | 필수 여부 |
|---|---|---|
| Apple Developer Program | $99/년 | iOS 출시 시 필수 |
| Google Play Console 등록 | $25 (1회) | Android 출시 시 필수 |
| EAS Build (Expo 클라우드 빌드) | 무료 티어(월 15회 iOS+15회 Android)로 MVP 단계 충분, 초과 시 $19/월(Starter)부터 | MVP는 무료로 가능 |
| 개인정보처리방침 호스팅 | $0 (Notion/GitHub Pages 무료 호스팅) ~ $15/년(도메인 구매 시) | 필수(스토어 심사 요건) |
| 앱 아이콘/스토어 이미지 | $0(직접 제작) ~ $50~200(외주 시) | 선택 |
| 실기기 테스트 | 보유 중인 iPhone/Android 기준 $0, 없을 경우 별도 구매 필요 | 필수(에뮬레이터만으로는 카메라롤/영상 스크러빙 검증 불가) |

**최소 현금 지출: 약 $124 (iOS+Android 동시 출시 기준, Apple $99 + Google $25)**. Android 없이 iOS만 먼저 낸다면 $99로 시작 가능.

## 3. 착수 전에 확정해야 할 것들

1. **플랫폼 우선순위** — iOS/Android 동시 출시 vs iOS 먼저 (Apple Developer 계정 승인에 보통 1~2일 소요, 법인 명의면 더 걸릴 수 있음)
2. **실제 스윙 영상 확보 계획** — 마킹/템포 계산 로직을 실제 골프 스윙 영상으로 검증해야 함. 본인이 연습장에서 직접 촬영할지, 기존 영상을 쓸지
3. **실기기 보유 현황** — iOS/Android 각각 테스트 가능한 기기가 있는지 (영상 스크러빙·프레임 탐색은 시뮬레이터로 완전히 검증 안 됨)
4. **앱 이름/아이콘/브랜드** — 스토어 등록 전에 확정 필요 ("Tour Tempo"라는 명칭은 원조 브랜드가 있으므로 이름·로고에 그대로 쓰지 않도록 주의 — 개념 인용은 괜찮지만 상표 자체를 앱 이름으로 쓰는 건 피해야 함)
5. **개인정보처리방침 게시 위치** — 도메인을 새로 살지, 무료 호스팅(Notion 페이지 등)으로 충분한지
6. **Apple Developer 계정 명의** — 개인 vs 사업자 (사업자로 하면 서류 심사가 추가로 붙어 시간이 더 걸림)
7. **서브에이전트 실제 등록 승인** — `ORG_CHART.md`/`company-organization.md`에 설계된 `golf-strategy-lead` 등 서브에이전트들을 `.claude/agents/`에 실제로 등록할지 (아직 사용자 승인 대기 상태)
8. **투입 가능 시간** — 파트타임/풀타임 여부에 따라 위 로드맵의 6~10주 vs 3~5주가 갈림
